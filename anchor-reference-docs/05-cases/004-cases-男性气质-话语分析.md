## 核心内容
- 方法：对 Reddit NoFap 论坛发帖的话语分析（discourse analysis）。
- 发现一：成员调用"理想化的天生男性气质"与"需要真实性爱（real sex）"的话语，为抵制色情与手淫正名。
- 发现二：悖论——成员必须"表演"那些据称是天生的特质；同时 outright 拒绝女权主义对色情的批判。
- 理论贡献：对流行的"使用者效应"范式（即用户因生物驱力受扰而戒色）提出替代解释——部分戒色行为是为了让色情使用与规范性男性气质的期待相调和。
