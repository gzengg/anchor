## 核心内容
- 期刊：Current Addiction Reports（2022年第9卷第2期，80-85页），同行评审综述。
- 主题：中国语境下问题性色情使用的研究进展，包括发生率估计、评估工具的中文版验证、以及文化与社会因素（如对性的保守态度、道德观念）如何塑造"自认有问题"的报告。
- 与西方发现呼应：中国样本中同样存在"道德不一致"式的自我归因模式——对色情的道德否定态度与实际使用行为之间的冲突，是报告"色情问题"的重要来源（与 Grubbs 等的 PPMI 模型一致）。
- 对内容库的意义：中文世界缺乏正规媒体的深度戒色报道与本土大型调查，该综述是可引用的中文学术锚点；直接采集中文社区"戒色吧"类经验帖不符合本库收录标准，故以学术综述替代。
