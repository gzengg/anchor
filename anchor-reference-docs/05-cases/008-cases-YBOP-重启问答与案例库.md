## 核心内容
- 社区共识（FAQ）：平均重启约 90 天（30±天的个体差异）；强烈建议设定目标（如100天）并切分为小目标（3天→1周→2周→3周→1个月→1.5个月→2个月→3个月→100天）。
- 术语：flatline＝对性/一切失去欲望的阶段，"只是个阶段，会过去"；edging（不高潮的手淫）被视为复发高风险行为。
- "重启后再看一次色情"被认为会约倒退1/3进度，并可能引发 binge（失控性放纵）而毁掉整个重启。
- 成功案例示例（18岁，121天）：报告"诸多获益"，但均为自我归因。

## 戒断时间线（如适用）
- 90天框架：社区把 90 天作为"标准重启"里程碑，30/60/90 天为常见打卡节点；flatline 可出现在戒断早期并持续数周。

## 应对方法（如适用）
- 目标切分法（chunking）：把100天拆成 3天/1周/2周/1月 等小里程碑。
- 环境控制：删除收藏、书签与素材；使用 K9、DNS 屏蔽等工具（FAQ 同时承认屏蔽工具"并非万无一失，只是减速带"）。
- 写日志：在论坛 journal 区记录背景与进度，并通过支持他人获得社区互动。
- 社区建议如有 ED 可暂缓性生活，否则真实亲密有助于"重启"性欲（此建议无临床依据，需谨慎对待）。

## 参考信息
- 偏差说明：论坛活跃用户自我选择样本，成功者更可能发帖（幸存者偏差）；数字（90天、倒退1/3）为社区经验法则而非研究数据。credibility：低。
