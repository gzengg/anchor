## 核心内容
- 常见自我报告戒断症状清单：失眠与睡眠困难；焦虑、压力与恐惧；头痛及肌肉/关节/牙齿/下颌/生殖器疼痛僵硬；疲劳虚弱；抑郁、绝望；烦躁不安；注意力涣散（脑雾）；情绪波动；易怒、挫败感；类流感症状、恶心、发热感；性欲低下或消失（flatline，可延迟数日出现并持续很久）；色情画面闪回与性梦；性渴求与冲动；回避社交。

- 多人报告戒断症状可断断续续持续数月（网站将其类比为 PAWS——急性期后戒断综合征）。

## 戒断时间线（如适用）
- 站内典型个案时间线（18岁男性，自我报告）：第1-12天"感觉极好"；第16-25天进入 flatline，疲倦、悲伤但渴求强烈；第26-60天大体平稳但"感觉有变化在发生"；第61-76天出现严重戒断与 flatline 症状（抑郁、焦虑、极度孤独、无望感、失眠、无性欲）；第80天后"基本一帆风顺"。
- 另一自我报告：前三天完全无法入睡、易激惹、抑郁焦虑、类流感症状持续一个月。
- 多数报告：戒断最强烈期集中在第1-3周；第2-4周被多人描述为"最艰难（ROUGH）"。
