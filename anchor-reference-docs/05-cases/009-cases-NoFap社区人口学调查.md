## 核心内容
- 样本性质：NoFap 官网社区投票（2012年4月），参与者为自愿填答的社区成员。
- 人口学：97% 男性，3% 女性；91% 异性恋男性；72% 白人、6% 亚裔、4% 西语裔；51% 美国、21% 西欧、9% 加拿大、5% 澳大利亚。
- 性状况：44% 自报是处男；20% 过去6个月无性行为；26% 自报在恋爱关系中（含5%已婚）；仅3%有子女。
- 用途：说明戒色社区的主体构成——以年轻、无固定性伴侣的西方男性为主，这直接影响"戒色经验"的适用边界。

## 参考信息
- 偏差说明：在线自愿投票，样本量与回收方式未披露，存在明显自选偏差与"深度用户"偏差；数据为2012年，社区规模此后已大幅扩张（r/NoFap 2022年已接近百万订阅），画像可能已变化。credibility：低。
