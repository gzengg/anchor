## 核心内容
- 样本：通过非主题 Reddit 帖子招募的在线问卷，n = 1063；多数人报告曾尝试戒撸。
- 核心发现：戒色动机最强的预测因素是态度性的——"认为手淫有害健康"这一信念；与性欲亢进（hypersexuality）有相关性，但与行为标志（如最大高潮次数）无显著相关。
- 戒色动机更高者：感知手淫影响更大、政治更保守、宗教性更高、对科学信任更低。
- 作者观点：研究戒色现象有助于理解"平均频率的健康行为如何被病理化"——即部分戒色者可能是把正常行为当成了病。
