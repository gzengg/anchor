## 核心要点
- 机制：纳曲酮为阿片受体拮抗剂，阻断内源性阿片对多巴胺奖赏的放大，理论上降低强迫行为的"奖赏感"与渴求（与酒精依赖用药逻辑平行）。
- 样本：20 名 27-60 岁（平均 38.8 岁）CSBD 男性，非司法门诊求治者；剂量 25-50mg/日，4 周；基线、治疗中、停药 4 周后测量。
- 结果：治疗期间 HD:CAS（主要结局）与 HBI 分显著下降；停药后部分效果保留，但 HD:CAS 回升提示症状反弹——可能需要持续用药。
- 安全性：疲劳 55%、恶心 30%、眩晕 30%、腹痛 30%；无导致停药的严重不良事件。
- 定位：FDA 未批准 CSBD 适应症，属超说明书使用；2022 年 WFSBP 指南视其为"最相关"的药物选项之一，但承认证据有限。

## 方法步骤
1. 由精神科/性医学专科医生评估确诊 CSBD，排除双相躁狂、物质与药物（多巴胺能药）所致。
2. 基线检查：肝功能、肾功能；确认无阿片类药物使用（需脱毒 7-10 天以上）。
3. 起始 25mg/日评估耐受，耐受后升至 50mg/日。
4. 每 3-6 个月监测肝功能；告知常见副作用（疲劳、恶心、眩晕、腹痛）。
5. 与心理治疗（CBT 首选）联合，而非替代。
6. 停药需医生指导；注意研究显示停药后症状可能反弹。

## 关键数据 / 证据
- HD:CAS 与 HBI 治疗期间显著下降（J Sex Med 2020;17(8):1544-1552，DOI: 10.1016/j.jsxm.2020.04.318）。
- 副作用率：疲劳 55%、恶心/眩晕/腹痛各 30%。
