## 核心要点
- 数据来自第二届澳大利亚健康与关系研究（ASHR2）：计算机辅助电话访谈，代表性样本为男性 9,963 人、女性 10,131 人（16–69 岁），总参与率 66%。
- **一生使用率**：男性 84%、女性 54%。
- **过去一年使用**（在看过者中）：男性 76%、女性 41%。
- **自认"对色情成瘾"**：男性仅 **4%**、女性仅 **1%**；且自认成瘾者中约半数同时报告色情使用对自己产生了不良影响。
- 结论：观看色情内容在澳大利亚相当普遍，但报告不良后果者仅为少数——"普遍使用"与"问题使用"必须区分。
- 这是戒色内容中常被引用的关键参照系：大众使用率（84%/54%）与自认成瘾率（4%/1%）之间存在数量级差异。

## 关键数据
- 样本：N=20,094（男 9,963 / 女 10,131），参与率 66%
- 一生使用：男 84% / 女 54%；过去一年（使用者中）：男 76% / 女 41%
- 自认成瘾：男 4% / 女 1%
